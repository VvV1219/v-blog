# 后端学习笔记导航

后端学习笔记按三个主题分别整理，选择下方入口阅读。

| 笔记 | 主要内容 |
| --- | --- |
| [基础知识学习笔记](../backend/basic-knowledge-notes.md) | 程序与进程、Shell、环境检查、DNS/TCP、HTTP、Cookie 与 Token |

## 建议复习顺序

1. **基础知识**：先理解程序如何运行、请求如何到达服务端。
2. **MySQL**：理解数据如何组织、查询与修改。
3. **Go**：理解入口程序、包与代码调用，再逐步学习后端接口开发。

每份笔记都保留了复习导航、代码示例和易错点，后续随学习进度更新。
